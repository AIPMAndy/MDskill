## 📦 安装

### 系统要求
- macOS 11.0 或更高版本
- Apple Silicon (M1/M2/M3/M4) 或 Intel 芯片
- 至少 100 MB 可用空间

### 下载安装
1. 下载 `MDSKILL-1.0.0-arm64.dmg`
2. 双击打开 DMG 文件
3. 拖拽到 Applications 文件夹
4. 右键点击选择"打开"

详细安装说明请查看 [安装指南](INSTALL.md)

## 🚀 快速开始

### 创建新文档
```
Cmd+N 或点击"新建"按钮
```

### 打开现有文档
```
Cmd+O 或点击"打开"按钮
```

### 编辑 Markdown
在左侧编辑器中输入内容，右侧实时预览效果。

### 保存文档
```
Cmd+S 或点击"保存"按钮
```

更多使用技巧请查看 [快速开始指南](QUICKSTART.md)
