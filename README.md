## 🚀 快速开始

### 系统要求
- macOS 11.0 或更高版本
- Apple Silicon (M1/M2/M3/M4) 或 Intel 芯片
- 至少 200 MB 可用空间

### 安装步骤

1. **下载安装包**
   - 下载 `MDskill-1.7.3-arm64.dmg` 文件

2. **安装应用**
   - 双击打开 DMG 文件
   - 将 `MDskill.app` 拖动到 `Applications` 文件夹
   - 如提示替换旧版本，选择"替换"

3. **启动应用**
   - 从 `Applications` 文件夹启动 MDskill
   - 首次启动可能需要在"系统偏好设置 > 安全性与隐私"中允许运行

4. **开始使用**
   - 点击"新建窗口"或"打开文件"开始编辑
   - 尽情享受高效的 Markdown 编辑体验！

## 🔍 文档搜索功能（新）

### 使用方法

#### 方式一：点击按钮
- 点击工具栏的 🔍 **搜索按钮**
- 点击工具栏的 📋 **大纲按钮**

#### 方式二：快捷键
- 按 `Cmd+F` 打开搜索面板
- 按 `Cmd+Shift+O` 打开大纲导航

### 搜索功能
- **关键词搜索** - 输入关键词实时搜索
- **正则表达式** - 点击 `.*` 按钮启用正则模式
- **大小写敏感** - 点击 `Aa` 按钮切换
- **智能填充** - 选中文本后打开搜索，自动填充
- **导航匹配** - 使用 `Enter` / `Shift+Enter` 浏览结果
- **结果计数** - 显示当前位置（如：3/15）

### 大纲导航
- **自动提取** - 自动提取文档中的所有标题
- **层级显示** - 按标题层级（# ~ ######）缩进显示
- **快速跳转** - 点击标题直接跳转到对应位置
- **当前高亮** - 自动高亮当前编辑位置的标题

### 搜索技巧
```
# 普通搜索
搜索：文档
结果：匹配"文档"这个词

# 正则搜索（启用 .* 按钮）
搜索：\b\w{5}\b
结果：匹配所有5个字母的单词

搜索：^\#\# 
结果：匹配所有二级标题
```

## 🐛 常见问题

### 应用无法打开
**问题**：提示"无法打开，因为它来自身份不明的开发者"

**解决方法**：
1. 打开"系统偏好设置" > "安全性与隐私"
2. 点击"仍要打开"按钮
3. 或者在终端执行：
   ```bash
   xattr -cr /Applications/MDskill.app
   ```

### 搜索功能不显示
**问题**：点击搜索按钮没有反应

**解决方法**：
1. 确认已安装最新版本（1.7.3 或更高）
2. 重启应用
3. 如仍有问题，联系微信：**AIPMAndy**

### 主题切换不生效
**问题**：切换主题后预览没有变化

**解决方法**：
1. 点击主题选择器确认主题已切换
2. 检查是否有内容在编辑器中
3. 尝试重新输入内容或重启应用

### 复制到微信公众号格式乱了
**问题**：粘贴到微信后格式不正确

**解决方法**：
1. 使用 Safari 或 Chrome 浏览器打开微信公众号后台
2. 使用 `Cmd+Shift+W` 快捷键复制
3. 在编辑器中使用 `Cmd+V` 粘贴
4. 建议选择"微信风格"主题
