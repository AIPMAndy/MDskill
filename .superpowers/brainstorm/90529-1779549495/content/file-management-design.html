核心使用性优化：文件管理 + 搜索历史

聚焦真正影响使用体验的功能，其他暂不优化

你提出的两个核心需求

需求1

文件夹管理 - 项目式工作流

用户场景：

  • 导入一个文件夹（如：我的知识库、项目文档）
  • 在侧边栏看到所有 .md 文件
  • 快速切换不同文件，无需重复打开
  • 保持工作上下文，不丢失编辑状态

参考产品：

  • VS Code - 左侧文件树
  • Typora - 文件列表侧边栏
  • Obsidian - 文件管理器
需求2

搜索 + 历史记录

用户场景：

  • 快速搜索文件名或内容
  • 查看最近打开的文件
  • 快速回到之前编辑的文档
  • 不用记住文件路径

参考功能：

  • Cmd+P 快速搜索（VS Code 风格）
  • 最近文件列表（Cmd+E）
  • 全文搜索（Cmd+Shift+F）

💡 我的建议

推荐方案A：轻量级文件管理

原因：

  • 满足你提出的核心需求：打开文件夹、快速切换、搜索历史
