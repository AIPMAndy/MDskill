## 👥 用户授权流程

### 用户侧操作

1. **下载安装 MDSKILL**

5. **输入授权码**
   - 收到授权码后（格式：`MDSK-XXXXX...`）

   - 点击"激活"

6. **激活成功**

   - 可以使用所有专业功能

## 📞 用户常见问题

### Q1: 如何激活？
A: 菜单栏 → 帮助 → 激活专业版，获取设备指纹后联系微信 AIPMAndy

### Q2: 可以在几台电脑上用？
A: 默认3台，超过需购买新的授权码

### Q3: 换电脑怎么办？
A: 新电脑重新激活即可，旧设备会自动失效（达到3台上限时）

### Q4: 离线能用吗？
A: 可以，激活后5天内离线可用

### Q5: 授权码能转让吗？
A: 不能，授权码绑定购买者账号

### Q6: 退款怎么办？
A: 联系开发者，授权码会被禁用

## 🆘 故障排查

### 用户无法激活

**可能原因**：
1. 网络问题 - 检查防火墙 3000 端口
2. 授权码错误 - 检查是否完整复制
3. 授权码已禁用 - 在数据库查询
4. 服务器宕机 - `pm2 status` 检查

**解决方案**：
```bash
# 1. 检查服务状态
pm2 status mdskill-license

# 2. 检查端口
netstat -tlnp | grep 3000

# 3. 测试API
curl http://localhost:3000/health

# 4. 查看日志
pm2 logs mdskill-license --lines 100
```

### 用户说"授权失效"

**可能原因**：
1. 离线超过5天
2. 授权码被禁用
3. Token 过期

**解决方案**：
- 让用户联网后重启应用
- 或重新输入授权码激活
