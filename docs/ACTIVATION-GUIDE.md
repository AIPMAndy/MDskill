# MDSKILL 激活码系统使用指南

## 系统概述

MDSKILL 采用月付会员制（19元/月），通过激活码手动激活。

### 会员权益
- ✅ 30天免费试用
- ✅ 复制到微信公众号
- ✅ 复制到博客
- ✅ 复制HTML源码
- ✅ 导出PDF
- ✅ 13种精美主题

## 客服操作流程

### 1. 收到用户付款
用户通过微信/支付宝扫码支付后，截图发送给客服。

### 2. 生成激活码
1. 打开 `tools/activation-code-generator.html`（在浏览器中）
2. 输入用户ID（从用户应用中获取，或使用微信号）
3. 选择会员时长：
   - 1个月：19元
   - 3个月：57元
   - 6个月：114元
   - 1年：99元 ⭐️ 推荐（省129元）
4. 添加备注（例如：微信用户张三，已确认支付）
5. 点击「生成激活码」
6. 复制激活码发送给用户

## 用户操作流程

### 1. 获取用户ID
1. 打开 MDSKILL 应用
2. 点击菜单栏「帮助」→「订阅管理」
3. 在订阅窗口中查看并复制用户ID
4. 将用户ID发送给客服

### 2. 支付会员费用
1. 扫描客服提供的支付二维码
2. 选择会员时长：
   - 月付：¥19/月
   - 年付：¥99/年（推荐，省¥129）
3. 完成支付并截图
4. 将支付截图发送给客服

### 3. 激活会员
1. 收到客服发送的激活码
2. 在订阅管理窗口点击「我有激活码」
3. 粘贴激活码
4. 点击「激活」按钮
5. 看到「激活成功」提示

### 4. 验证激活
- 订阅状态变为「付费会员」
- 显示正确的到期日期
- 所有专业功能可用

## 技术细节

### 激活码格式
```
[Base64编码的数据]|[HMAC-SHA256签名]
```

### 数据结构
```json
{
  "userId": "用户ID",
  "months": 1,
  "expiryDate": "2026-06-08T01:23:07.491Z",
  "timestamp": 1778203387491
}
```

### 安全性
- 使用 HMAC-SHA256 签名防止伪造
- 密钥存储在服务端，不对外公开
- 每个激活码包含时间戳，确保唯一性

## 常见问题

### Q: 激活码可以重复使用吗？
A: 不可以。每个激活码只能使用一次。

### Q: 激活码有有效期吗？
A: 激活码本身没有有效期，但建议在生成后24小时内使用。

### Q: 如何查看剩余会员天数？
A: 打开「帮助」→「订阅管理」，查看「会员剩余 X 天」。

### Q: 会员到期后会怎样？
A: 到期前3天会显示续费提醒。到期后专业功能将被锁定，但基础功能仍可使用。

### Q: 如何续费？
A: 重复上述流程，新的会员时长会在当前到期日基础上延长。
