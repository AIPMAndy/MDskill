## 2. 功能概述

### 2.1 核心需求
基于用户反馈，当前产品缺少以下关键功能：

1. **文件夹管理** - 用户希望导入一个文件夹，在侧边栏看到所有 .md 文件，快速切换不同文件
2. **搜索与历史** - 用户需要快速搜索文件名/内容，查看最近打开的文件

### 2.2 设计原则
- **YAGNI** - 只做必要的功能，不过度设计
- **轻量级** - 保持产品简洁，不做成文件管理器
- **高效** - 提升内容创作者的工作效率

### 3.2 侧边栏设计

#### 3.2.1 顶部操作区
```html
┌─────────────────────────┐
│  📁 打开文件夹           │  ← 按钮
├─────────────────────────┤
│  🔍 搜索文件...          │  ← 搜索框
└─────────────────────────┘
```

#### 3.2.2 最近打开区域
```html
┌─────────────────────────┐
│  最近打开               │  ← 标题
├─────────────────────────┤
│  📄 产品设计文档.md     │  ← 文件项（高亮）
│  📄 会议记录.md         │
│  📄 技术方案.md         │
└─────────────────────────┘
```
- 显示最近打开的 10 个文件
- 当前打开的文件高亮显示
- 点击切换文件

#### 3.2.3 当前文件夹区域
```html
┌─────────────────────────┐
│  当前文件夹             │  ← 标题
│  /Users/andy/docs       │  ← 路径
├─────────────────────────┤
│  📄 README.md           │
│  📄 CHANGELOG.md        │
│  📁 docs/               │  ← 文件夹（点击展开）
│  📄 产品设计.md         │
└─────────────────────────┘
```
- 显示当前文件夹的所有 .md 文件
- 支持一级子文件夹展开（不递归）
- 点击文件切换编辑

### 3.3 搜索功能

#### 3.3.1 快速搜索文件（Cmd+P）
- 弹出搜索框（居中浮层）
- 模糊匹配文件名
- 实时显示匹配结果
- 上下键选择，回车打开

#### 3.3.2 最近文件（Cmd+E）
- 弹出最近文件列表
- 显示最近 20 个文件
- 按打开时间倒序排列

#### 3.3.3 全文搜索（Cmd+Shift+F）
- 在当前文件夹中搜索内容
- 显示匹配的文件和行号
- 点击跳转到对应位置

## 4. 技术架构

### 4.1 数据结构

#### 4.1.1 文件夹状态
```javascript
{
  currentFolder: '/Users/andy/docs',
  files: [
    { path: '/Users/andy/docs/README.md', name: 'README.md', type: 'file' },
    { path: '/Users/andy/docs/docs', name: 'docs', type: 'folder' }
  ]
}
```

#### 4.1.2 历史记录
```javascript
{
  recentFiles: [
    { path: '/Users/andy/docs/产品设计.md', lastOpened: 1716451200000 },
    { path: '/Users/andy/docs/会议记录.md', lastOpened: 1716450000000 }
  ]
}
```

### 4.2 核心模块

#### 4.2.1 文件管理器（file-manager.js）
```javascript
class FileManager {
  // 打开文件夹
  async openFolder(folderPath)
  
  // 获取文件列表
  async getFiles(folderPath, recursive = false)
  
  // 监听文件变化
  watchFolder(folderPath, callback)
}
```

#### 4.2.2 历史管理器（history-manager.js）
```javascript
class HistoryManager {
  // 添加历史记录
  addToHistory(filePath)
  
  // 获取最近文件
  getRecentFiles(limit = 10)
  
  // 清除历史
  clearHistory()
}
```

#### 4.2.3 搜索引擎（search-engine.js）
```javascript
class SearchEngine {
  // 搜索文件名
  searchFiles(query, files)
  
  // 全文搜索
  async searchContent(query, folderPath)
}
```

### 4.3 状态持久化
使用 `electron-store` 保存：
- 当前打开的文件夹路径
- 最近打开的文件列表（最多 20 个）
- 侧边栏展开/收起状态

## 10. 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|----------|
| 大文件夹性能问题 | 高 | 限制显示数量，分页加载 |
| 文件监听占用资源 | 中 | 使用节流，仅监听当前文件夹 |
| 搜索速度慢 | 中 | 使用索引，异步搜索 |
| 状态同步问题 | 低 | 使用 electron-store 可靠存储 |
