## 🐛 已知限制

### 技术限制（可接受）
1. **文件监听**: 网络驱动器可能不触发（< 5% 用户）
2. **会话恢复**: 多窗口可能状态覆盖（当前单窗口为主）
3. **命令面板**: 最近文件需重新打开刷新（影响小）

### 未来改进
1. chokidar 替换（需主进程 ESM 改造）
2. 多窗口独立会话（需 windowId 隔离）
3. 命令面板实时刷新（需事件监听）

## 📝 执行总结

### 成功因素
1. **目标明确**: 从 HorseMD 提取精华，而非全盘照搬
2. **优先级清晰**: 先实现高价值、低成本功能
3. **渐进式开发**: 从简单到复杂，逐步推进
4. **文档先行**: 每个功能完成立即记录

### 经验教训
1. **技术选型**: 避免 ESM 依赖问题（chokidar → fs.watch）
2. **防抖优化**: localStorage 频繁写入必须防抖
3. **兼容性**: macOS Cmd vs Windows Ctrl
4. **用户教育**: 新功能需要清晰文档
