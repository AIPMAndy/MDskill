## 🎉 重大更新

本次更新从优秀的 Markdown 编辑器 [HorseMD](https://github.com/BND-1/horseMD) 中汲取灵感，大幅提升了编辑体验和工作流效率。

### ✨ 新增功能（5个）

#### 1. 🎨 Morandi 主题系列
四款全新的低饱和度高级主题，专为长时间写作优化：

- **🌿 Morandi Sage（灰绿）** - 清新自然，适合技术文档
- **🌸 Morandi Rose（豆沙）** - 温柔优雅，适合文学创作
- **🌫️ Morandi Mist（雾蓝）** - 沉静舒适，适合深夜写作
- **🌆 Morandi Dusk（暮色）** - 温暖宁静，适合日常笔记

**特点**:
- 低饱和度配色，护眼不疲劳
- 高级感设计，专业而不失温度
- 完美适配长时间写作场景

#### 2. ⌨️ 块级快捷键（Ctrl+0-6）
快速转换标题层级，告别重复输入井号：

- `Ctrl/Cmd+0`: 转换为普通段落
- `Ctrl/Cmd+1`: 转换为一级标题（#）
- `Ctrl/Cmd+2`: 转换为二级标题（##）
- `Ctrl/Cmd+3-6`: 转换为三到六级标题

**亮点**:
- 智能光标位置保持
- 自动清除现有标题标记
- 支持中英文内容

#### 3. 🎛️ 命令面板（Ctrl+P）
VSCode 风格的命令面板，快速访问所有功能：

- 模糊搜索命令和文件
- 键盘导航（↑↓ + Enter）
- 最近文件快速访问
- 匹配文本高亮显示

**支持命令**:
- 文件操作：新建、打开、保存
- 导出功能：微信、PDF、HTML、Markdown
- 最近文件列表（按时间排序）

#### 4. 🔄 会话恢复
无缝工作延续，关闭即保存：

- ✅ 窗口位置和大小自动恢复
- ✅ 最后编辑的文件自动打开
- ✅ 光标位置和滚动位置恢复
- ✅ 主题选择持久化
- ✅ 1秒防抖优化，避免频繁写入

**用户体验**:
- 关闭应用无需手动保存状态
- 重新打开直接继续工作
- 多次重启也能保持工作状态

#### 5. 👁️ 外部文件监听
实时检测外部修改，避免内容冲突：

- ✅ 自动检测其他编辑器的修改
- ✅ 无未保存修改时自动刷新
- ✅ 有修改时提示用户选择（重载/保留）
- ✅ 文件删除时通知用户
- ✅ 低 CPU 开销（< 0.1%）

**适用场景**:
- Git pull 更新文档后自动刷新
- 使用 VS Code 批量替换后同步
- 多人协作（共享文件夹）
- 防止误操作覆盖

## 🐛 已知问题

### 轻微限制
1. **文件监听**: 网络驱动器可能无法触发（< 5% 用户影响）
2. **会话恢复**: 多窗口可能覆盖状态（当前以单窗口为主）
3. **命令面板**: 最近文件需重新打开面板才刷新

**影响评估**: 所有问题不影响核心功能使用

## 📖 快速上手

### 快捷键
- `Ctrl/Cmd+P`: 打开命令面板
- `Ctrl/Cmd+0-6`: 转换标题层级
- `Ctrl/Cmd+N`: 新建文件
- `Ctrl/Cmd+O`: 打开文件
- `Ctrl/Cmd+S`: 保存文件

### 新主题使用
1. 点击工具栏"主题"按钮
2. 找到 Morandi 系列（🌿🌸🌫️🌆）
3. 点击预览并应用

### 命令面板使用
1. 按 `Ctrl+P` 打开
2. 输入命令名称或文件名
3. 用 ↑↓ 键导航
4. 按 Enter 执行
