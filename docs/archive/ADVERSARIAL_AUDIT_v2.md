## 🔴 严重问题（P0）- 立即修复

### 1. **运行时错误消息未国际化** ⭐⭐⭐⭐⭐
**影响**: 用户看到中文错误提示，完全无法理解问题
**文件**: `renderer/renderer.js`

**问题代码**:
```javascript
line 237: alert(`应用初始化失败: ${error.message}`);
line 948: alert('AI 格式化失败: ' + error.message);
line 528: alert('复制功能模块未加载，请刷新页面重试');
line 558: alert('复制功能模块未加载，请刷新页面重试');
```

**用户体验**:
1. 启动应用失败 → 看到中文 alert，不知道发生了什么
2. AI 格式化失败 → 中文弹窗，无法理解
3. 复制功能失败 → 中文弹窗，无法理解

**方案**:
- 所有 `alert()` 替换为 `window.i18nHelpers.showAlert(key)`
- 添加翻译键：`errors.initFailed`, `errors.aiFormatFailed`, `errors.copyModuleNotLoaded`

---

### 2. **Confirm 对话框混合中英文** ⭐⭐⭐⭐⭐
**影响**: 会员到期提示有 i18n 机制但有降级逻辑
**文件**: `renderer/renderer.js`

**问题代码**:
```javascript
line 800: } else if (confirm(`⏰ 会员即将到期\n\n${message}\n\n是否立即续费？`)) {
line 816: } else if (confirm(`😢 会员已过期\n\n${message}\n\n是否立即续费？`)) {
line 1193: } else if (confirm(`${message}\n\n是否查看会员权益？`)) {
```

**问题**: 有 `window.i18nHelpers.showConfirm()` 但降级到硬编码中文 `confirm()`

**方案**:
- 移除降级逻辑
- 确保 i18nHelpers 在所有页面加载

---

### 3. **Toast 提示未国际化** ⭐⭐⭐⭐
**影响**: 保存、复制、导出等所有操作反馈都是中文
**文件**: `renderer/copy-utils.js`, `renderer/renderer.js`

**用户体验测试**:
1. 点击 "Copy to WeChat" → Toast 显示 "复制成功" ❌
2. 保存文件 → Toast 显示 "保存成功" ❌
3. 导出 PDF → Toast 显示 "导出成功" ❌
4. AI 格式化 → Toast 显示 "正在格式化..." ❌

**问题**: `showToast()` 接收的都是硬编码中文字符串

**方案**:
```javascript
// 当前
showToast('复制成功');

// 应该改为
showToast(t('messages.copySuccess'));
```

需要修改所有调用 `showToast()` 的地方（预计 20+ 处）

---

### 4. **激活页面部分中文** ⭐⭐⭐⭐
**影响**: 用户看到激活页面标题是中文
**文件**: `renderer/activation.html`

**问题**:
```html
line 5: <title data-i18n="activateTitle">激活专业版 - MDSKILL</title>
```

虽然有 `data-i18n` 属性，但默认显示中文，用户第一眼看到的是中文。

**方案**:
- 默认英文：`<title>Activate Pro - MDSKILL</title>`
- 让 i18n 脚本动态更新
