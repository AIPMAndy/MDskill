## 已修复问题

### 问题1: Base64 大小写敏感
**原因**: 将 base64 字符串转换为大写导致解码失败
**解决**: 保持 base64 原始大小写

### 问题2: 签名验证失败
**原因**: 格式化时 base64 和签名混在一起
**解决**: 使用 `|` 分隔 base64 和签名部分
