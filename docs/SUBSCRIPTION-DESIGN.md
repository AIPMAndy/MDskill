# MDSKILL 月会员制设计文档

## 商业模式升级

### 从买断制到订阅制

**原模式：** 一次性付费，永久使用
**新模式：** 月会员订阅，持续收入

### 定价策略

- **月会员：** 19元/月
- **新用户福利：** 30天免费试用
- **续费提醒：** 到期前3天提醒

## 技术架构

### 1. 在线授权验证系统

```
客户端 <---> 授权API服务器 <---> 数据库
```

**API端点设计：**

```
POST /api/v1/auth/trial
- 功能：开通试用
- 参数：deviceId, email (可选)
- 返回：trialEndDate, userId

POST /api/v1/auth/verify
- 功能：验证会员状态
- 参数：userId, deviceId
- 返回：isActive, expiryDate, daysLeft

POST /api/v1/auth/subscribe
- 功能：订阅会员
- 参数：userId, paymentProof
- 返回：subscriptionId, expiryDate

GET /api/v1/auth/status
- 功能：查询会员状态
- 参数：userId
- 返回：status, expiryDate, autoRenew
```

### 2. 本地状态管理

**存储位置：** `~/.mdskill/subscription.json`

```json
{
  "userId": "uuid",
  "deviceId": "device-fingerprint",
  "status": "trial|active|expired",
  "trialStartDate": "2026-05-07",
  "expiryDate": "2026-06-06",
  "lastVerified": "2026-05-07T10:00:00Z",
  "autoRenew": false,
  "reminderShown": false
}
```

### 3. 会员状态枚举

```javascript
const SubscriptionStatus = {
  TRIAL: 'trial',           // 试用期
  ACTIVE: 'active',         // 付费会员
  EXPIRED: 'expired',       // 已过期
  GRACE: 'grace'            // 宽限期（可选）
}
```

## 用户流程

### 首次启动流程

```
1. 检测是否首次启动
2. 生成 deviceId
3. 调用 /api/v1/auth/trial 开通试用
4. 保存试用信息到本地
5. 显示"欢迎使用，您有30天免费试用"
```

### 日常使用流程

```
1. 启动应用
2. 读取本地 subscription.json
3. 检查 lastVerified 时间
4. 如果超过24小时，调用 /api/v1/auth/verify
5. 更新本地状态
6. 根据状态决定是否限制功能
```

### 到期提醒流程

```
1. 每次启动检查 daysLeft
2. 如果 daysLeft <= 3 且 reminderShown = false
3. 显示续费提醒弹窗
4. 设置 reminderShown = true
5. 提供"立即续费"和"稍后提醒"选项
```

### 过期处理流程

```
1. 检测到 status = expired
2. 显示"会员已过期"弹窗
3. 限制专业功能使用
4. 提供"立即续费"按钮
5. 允许查看内容，但禁止复制/导出
```

## 数据统计

### 关键指标

- **试用转化率：** 试用用户 → 付费用户
- **月活跃用户：** MAU
- **付费用户数：** Paying Users
- **月经常性收入：** MRR (Monthly Recurring Revenue)
- **流失率：** Churn Rate
- **客户生命周期价值：** LTV

### 埋点设计

## 风险与应对

### 风险1：在线验证失败

**应对：** 本地缓存最后验证结果，离线时使用缓存，但限制缓存有效期（7天）

### 风险2：用户破解

**应对：** 
- 设备指纹绑定
- 定期在线验证
- 异常行为检测

### 风险3：支付回调延迟

**应对：** 
- 提供手动刷新按钮
- 支付成功后轮询验证
- 客服手动激活通道

### 风险4：转化率低

**应对：**
- A/B测试定价
- 优化试用期体验
- 增加会员权益
- 限时优惠活动

## 复利效应

**为什么订阅制更好：**

1. **持续收入：** 每月稳定现金流
2. **用户粘性：** 订阅用户更活跃
3. **价值累积：** 用户越多，收入越高
4. **可预测性：** MRR 可预测增长
5. **估值更高：** SaaS 估值 = MRR × 倍数

**示例计算：**

```
假设：
- 月会员价格：19元
- 每月新增试用用户：100人
- 试用转化率：10%
- 用户留存率：80%

第1个月：10个付费用户，MRR = 190元
第2个月：10 + 10×0.8 = 18个付费用户，MRR = 342元
第3个月：18 + 10×0.8 = 26个付费用户，MRR = 494元
...
第12个月：约80个付费用户，MRR = 1520元

年收入：约10000元
```

这就是复利的力量！
