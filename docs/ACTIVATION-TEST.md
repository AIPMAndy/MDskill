# 激活码系统测试文档

## 测试时间
2026-05-08

## 系统概述
MDSKILL 已实现完整的激活码订阅系统：
- 30天免费试用
- 月付会员制（19元/月）
- 到期前3天提醒
- 激活码手动激活
- 功能权限控制

## 测试流程

### 1. 启动应用
- [x] 应用已启动（npm start）
- [ ] 验证订阅窗口是否自动打开

### 2. 重置订阅（清除终身会员）
- [ ] 打开订阅管理窗口
- [ ] 点击"重置订阅"按钮
- [ ] 确认订阅已清除

### 3. 验证试用期激活
- [ ] 确认显示"试用期剩余 30 天"
- [ ] 确认用户ID已生成
- [ ] 确认设备ID已生成

### 4. 测试功能权限
- [ ] 尝试使用"复制到微信公众号"功能
- [ ] 尝试使用"复制到博客"功能
- [ ] 尝试使用"复制HTML源码"功能
- [ ] 尝试使用"导出PDF"功能
- [ ] 尝试切换精美主题

### 5. 生成测试激活码
- [ ] 在浏览器中打开 `tools/activation-code-generator.html`
- [ ] 输入测试用户ID（从订阅窗口获取）
- [ ] 选择月数：1个月
- [ ] 添加备注：测试激活
- [ ] 点击"生成激活码"
- [ ] 复制生成的激活码

### 6. 使用激活码激活
- [ ] 在订阅窗口点击"我有激活码"
- [ ] 粘贴激活码
- [ ] 点击"激活"按钮
- [ ] 确认激活成功提示

### 7. 验证激活后状态
- [ ] 确认状态变为"付费会员"
- [ ] 确认显示正确的到期日期
- [ ] 确认所有专业功能可用

### 8. 测试到期提醒
- [ ] 修改到期日期为3天后（手动编辑 ~/.mdskill/subscription.json）
- [ ] 重启应用
- [ ] 确认显示续费提醒

## 关键文件位置

### 后端文件
- `activation-code-generator.js` - 激活码生成和验证逻辑
- `subscription-manager.js` - 订阅管理核心
- `main.js` - IPC 处理器

### 前端文件
- `renderer/subscription.html` - 订阅管理界面
- `renderer/renderer.js` - 功能权限检查

### 工具文件
- `tools/activation-code-generator.html` - 客服激活码生成工具

### 配置文件
- `~/.mdskill/subscription.json` - 订阅状态存储
